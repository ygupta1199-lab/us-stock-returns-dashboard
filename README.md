# 📈 US Stock Returns Dashboard

An interactive Streamlit web application that analyzes historical returns for US-listed stocks.

Enter a stock ticker such as `AAPL`, `MSFT`, `NVDA`, or `TSLA` and the dashboard retrieves historical market data and calculates monthly, quarterly, and annual percentage returns.

## 🚀 Features

- 📊 Analyze US-listed stocks
- 📅 Monthly percentage-change table
- 📆 Quarterly percentage-change table
- 📈 Annual percentage-change table
- 🟢 Positive returns highlighted in green
- 🔴 Negative returns highlighted in red
- 📉 Supports 5–20 years of historical data
- 💾 Download monthly, quarterly, and annual returns as CSV
- 💰 Uses Adjusted Close prices when available
- 🔄 Historical data retrieved automatically from Yahoo Finance
- 🌐 Can be deployed as a web application using Streamlit Community Cloud
